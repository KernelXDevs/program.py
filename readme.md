# Smart Home Appliance "Hacker" 🕵️‍♂️💻

A humorous, text-based Python script that simulates a "hacking" sequence targeting common smart home appliances. 

This program uses dramatic pauses and funny console outputs to make you feel like a movie hacker, though the only thing it actually does is print text to your screen.

## Features

* **Interactive Menu:** Choose which appliance you want to "compromise".
* **Suspenseful Output:** Utilizes `time.sleep()` to create fake loading sequences and dramatic tension.
* **Funny Scenarios:** Each choice has a unique, disastrous outcome for the appliance:
  * 🌡️ **Fridge:** Turns it into a 1000°C oven.
  * 🌪️ **Washing Machine:** Spins out of control at 100,000 RPM.
  * 🛑 **Microwave:** A long, grueling hacking attempt that ultimately fails.
  * 📺 **TV:** Glitches the screen to endless static.

## Prerequisites

* Python 3.x installed on your system.
* No additional external libraries are required (uses built-in `time` and `random` modules).

## How to Run

1. Save the code to a file, for example, `hacker_sim.py`.
2. Open your terminal or command prompt.

## Known Quirks (The "Features")

* **The Microwave Loop:** Hacking the microwave (Option 3) takes a very long time (about 50 seconds) before failing. Patience is a virtue!
* **Invalid Inputs:** If you enter anything other than 1, 2, 3, or 4, the program will simply exit without doing anything.

## Disclaimer

**This is a joke program.** It does not contain any malicious code, it does not connect to the internet, and it absolutely cannot hack your fridge, washing machine, microwave, or TV. It is meant for entertainment and basic Python learning purposes only.
